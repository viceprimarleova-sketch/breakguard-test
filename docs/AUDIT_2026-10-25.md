# rc2 pilot preparation audit — October 25, 2026

## What changed

Added limited static embedded GraphQL detection without embedded edits, local
coverage/limits reports, explicit operational error codes, source path guards,
atomic edits with snapshots and conflict-aware restore, and protection against
resetting existing Git review branches. Prepared an operator-only Sandbox payment
adapter, an offline fake checkout demonstration and bounded pilot documents.

## Verified evidence

- **75 tests passed** against a separately installed wheel using isolated Python
  imports on Linux / CPython 3.12. This includes the earlier 39 tests and new
  coverage for source lines, dynamic query skips, errors/JSON, paths, restore,
  disk-write rollback, branch protection and payment state/mismatch handling.
- A separate clean virtual environment installed the wheel and pinned dependency
  with `--no-index`. Its full synthetic CLI flow produced 3 initial findings,
  previewed/applied edits in 2 files, left 1 manual ScriptTag result, restored
  original bytes and refused to overwrite a later source edit.
- All installed Python modules and rule bytes match this source tree. The wheel
  SHA-256 and module hashes are in `audit-results-2026-10-25.json`.
- Public Shopify Ruby and React Router snapshots were scanned read-only. Each
  remained Git-clean. The Ruby source retains the known manual ScriptTag finding
  at `lib/shopify_app/managers/script_tags_manager.rb:106`; the React Router
  control has no supported deprecation findings. Coverage counts and exact
  commits are in the JSON record. No public source is included in the delivery kit.
- Payment tests use a fake transport, including successful/repeated capture,
  cancellation/unapproved/pending/mismatched amount/currency failures and sandbox
  host restrictions. The CLI demonstration is explicitly offline with no money
  received or fulfillment. **No actual PayPal Sandbox transaction was performed.**

## Reproduce

Install the exact wheel into a clean environment and run `scripts/release_smoke.py`.
For the full test suite install the test dependency and run from outside the
source directory:

```sh
python -I -m pytest -q --import-mode=importlib /absolute/path/to/repository/tests
```

The two external repository snapshots are:

- https://github.com/Shopify/shopify_app/tree/68fd8e4931b2934b6d70950bf398c79310d7268a
- https://github.com/Shopify/shopify-app-template-react-router/tree/48b841a7746e1b08d1e6d8793b1208f3096e41d0

## Limits and unresolved gates

The new candidate has not run hosted Windows/macOS/Python matrix checks because
publishing its review branch requires the Founder's approval. Previous rc1 CI
successes do not establish rc2's platform results. The public scans do not prove
real-application autofix safety, full recall, developer usefulness or willingness
to pay. No real Shopify API/schema request or application deployment was tested.

One consenting Shopify developer must complete the representative-code protocol.
Owner-controlled Sandbox access is required for a real provider test. Seller
identity/jurisdiction, final price/tax, approved terms and eventual live checkout
need separate review. No customer, payment or income is documented.
